# DungenManager — Roadmap

---

## Version 2.0 — Das aufgeschlagene Buch

### Kern-Konzept: Ort als kleinste Einheit

**Alt:**
```
Kampagne → Sessions → Szenen
```

**Neu:**
```
Kampagne → Orte → Szenen
```

Der DM bereitet **Orte** vor, nicht Sessions. Jeder Ort verhält sich wie eine eigene Session und hat ein **Gedächtnis** — was passiert ist, bleibt gespeichert. Besuchen die Helden einen Ort erneut, knüpft der DM direkt an der Handlung an, ohne von vorne anfangen zu müssen.

---

### Layout: Das aufgeschlagene Buch

Zwei Seiten, immer gleichzeitig sichtbar:

**Linke Seite** — persistent, sessionübergreifend:
- Weltkarte mit Orten
- Quest-Liste
- Audio-Mixer

**Rechte Seite** — kontextabhängig:

| Modus | Inhalt |
|-------|--------|
| Vorbereitung | Szenen des Ortes schreiben, NPCs verknüpfen, Encounter vorbereiten |
| Live-Session | Aktive Szene, Initiative-Tracker, Live-Notizen |

---

### Workflow

```
Vorbereitung  →  Live-Session
```

Kein separater Nachbereitungs-Schritt — das Gedächtnis des Ortes übernimmt diese Rolle automatisch.
